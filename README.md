## LLM NPC Brain

![Local LLM](https://img.shields.io/badge/Local_LLM-Operational-2ea44f?style=flat-square)
![Unreal Engine](https://img.shields.io/badge/Unreal_Engine-C++-0E1128?style=flat-square\&logo=unrealengine\&logoColor=white)
![StateTree](https://img.shields.io/badge/StateTree-Integration-0969da?style=flat-square)
![Structured Output](https://img.shields.io/badge/Output-Grammar_Constrained-6f42c1?style=flat-square)

A local LLM-based decision system for Unreal Engine NPCs.

The system converts NPC perception and gameplay context into a structured situation report, sends it to a locally running language model, restricts the model to an approved set of gameplay actions, validates the response, and routes the selected decision into Unreal Engine through Gameplay Tags and StateTree events.

The objective is not unrestricted AI behavior. The system gives NPCs limited decision-making initiative within developer-defined rules, available actions, safety constraints, and fallback behavior.

The project includes:

* Local llama.cpp runtime management
* GGUF model support
* CUDA and Vulkan backend selection
* Structured NPC perception data
* Dynamic prompt construction
* Grammar-constrained model output
* Priority-based NPC request processing
* Gameplay Tag action mapping
* StateTree event integration
* Decision logging and failure recovery
* Distance-based AI activation and fallback

The local LLM runtime and the initial Unreal Engine communication path are operational. Project-specific NPC behavior, prompt, and StateTree layers are being completed.

### AI Commerce Operations and Decision Support

![Inventory](https://img.shields.io/badge/Commerce-Operations-0969da?style=flat-square)
![Supplier Integration](https://img.shields.io/badge/Supplier-Integration-6f42c1?style=flat-square)
![Validation](https://img.shields.io/badge/Workflow-Validation-2ea44f?style=flat-square)
![Audit](https://img.shields.io/badge/Audit-Ready-d97706?style=flat-square)

An AI-oriented operational platform built on a customized inventory, supplier-integration, pricing, and workflow foundation.

The platform provides the structured data, permissions, validation mechanisms, service interfaces, and audit layers required for AI Agents and decision-support tools to operate safely within commerce workflows.

Its current technical foundation includes:

* Custom Master SKU and product-relationship management
* Pooled and effective stock calculation
* Controlled price synchronization
* Supplier-adapter architecture
* Secure supplier credential handling
* Integration job lifecycle management
* Operational validation and issue tracking
* Structured import and export services
* Permission-controlled workflows
* Traceable and recoverable operations

Together, the customer-facing and operational components form a broader AI commerce environment in which communication, structured business data, and controlled workflows support measurable analysis and decision assistance.

AI components operate through approved tools, explicit permissions, validation rules, traceable outputs, and human oversight rather than directly controlling business operations.

The ecosystem follows a hybrid development approach. Core data, security, validation, and business services are implemented through controlled custom code, while suitable low-code or visual workflow layers can support orchestration, prototyping, operational automation, and human-supervised processes.
